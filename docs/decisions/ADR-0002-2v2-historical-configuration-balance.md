# ADR-0002 — Historical configuration selection for 2v2 balance

Date: 2026-09-18
Status: Accepted

## Context

The historical 2v2 pilot needs two opposing two-ship forces that are reasonably comparable without inventing balancing bonuses or fictional ship statistics.

Individual sailing warships could change armament, complement, rig details and other service characteristics across their careers. Historical sources may also preserve more than one dated, documented configuration for the same vessel.

For this pilot, balance is useful because the scenario is intended to expose multi-ship assumptions and ship differentiation rather than to reproduce an intentionally asymmetric historical engagement.

## Decision

For the 2v2 pilot, when a candidate vessel has more than one genuinely documented and internally coherent historical configuration within the project's relevant period, the project may select the configuration that best improves overall two-side balance.

This is allowed only inside the historical evidence envelope for that individual ship. It is not permission to tune values freely.

Rules:

1. Prefer a complete, dated configuration actually documented for the individual vessel.
2. When several documented dated configurations are available, balance may be used as a selection criterion among them.
3. Do not combine armament from one date, crew from another, rig from a third and dimensions from a fourth to manufacture a synthetic optimum unless the combination itself is historically supportable and explicitly labelled as a reconstruction.
4. Do not treat a source disagreement or an uncertain range as a balancing slider. If one interpretation is materially better supported, use the better-supported interpretation even when it worsens balance.
5. Do not alter hull dimensions, gun calibres, gun counts, crew quality, sailing qualities or other historical characteristics beyond what reliable evidence supports.
6. Preserve provenance and the exact date/refit/state associated with the selected configuration.
7. If the selected four configurations do not balance sufficiently, change ship selection before inventing modifiers.
8. Any remaining asymmetry must be documented.

## Scenario consequence

The pilot does not need to represent an exact historical battle involving all four ships. It may be a historically plausible development scenario using historically valid ship configurations from a sufficiently close technological period.

If all four ships are represented in their Trafalgar-day state, the scenario may use the 21 October 1805 configuration label. If balance requires choosing another documented configuration for one or more ships, the pilot must stop presenting the quartet as an exact Trafalgar-date force and instead identify the specific configuration date for each ship.

## Consequences

- Balance can legitimately influence which historical configuration is selected.
- Historical fidelity remains the hard constraint; balance operates inside it.
- Configuration selection becomes an explicit research task rather than an implementation-time tuning task.
- The selected ship data must remain traceable to sources and internally coherent.
- Implementation remains blocked until the four selected configurations are documented sufficiently to close the research gate.
